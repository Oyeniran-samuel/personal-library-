# Personal Engineering Notes

A personal knowledge repository for documenting software engineering concepts,
architectures, lessons, mistakes, and practical things I learn while building
real-world projects.

This is not a production codebase.

The purpose of this repository is to help me understand **why systems are
designed the way they are**, not just how to make them work.

---

## 🎯 Main Goals

- Document important engineering concepts
- Understand backend architecture
- Record lessons from real projects
- Keep useful debugging solutions
- Understand design patterns through practical examples
- Document security and deployment practices
- Build a personal technical reference I can return to later

---

# 📚 Projects

## Grand Plus College AI Student Assistant

A backend architecture for an AI-powered student support assistant.

The project combines:

- TypeScript
- Node.js
- Express
- AI providers
- JSON knowledge bases
- Intent detection
- Chat services
- Ticket escalation
- Notifications
- Presence tracking
- Environment-based configuration

### Architecture

The system is divided into several layers:

1. Entry Point
2. AI Layer
3. Knowledge Base Layer
4. Chat Layer
5. Ticket Layer
6. Presence Layer
7. Shared Layer

See:

- [Architecture](projects/grand-plus-ai-assistant/architecture.md)
